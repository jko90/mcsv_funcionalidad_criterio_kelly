Manejando con nvm
Instalar la versionde nonde: nvm install 18.16.0
Utilizamos la versionde node: nvm use 18.16.0 

Instalamos: npm install @ionic-native/core@5.36.0 --legacy-peer-deps
Nuevo: npm install @capacitor-community/sqlite
(Verificamos la instalacion: npm list @ionic-native/core
                            npm list @ionic-native/sqlite)

Ejecutamos: npx ionic serv


Actualizar:
Primero actualizar versionde ionic: npm install @ionic/cli@latest --save-dev --legacy-peer-deps
Verifica actualizaciones: npm install -g npm-check-updates , npx ncu
actualizar pakage.json: npx npm-check-updates -u
Instalar nuevas dependencias: npm install --legacy-peer-deps
